📋 DETAILED SETUP:

┌─────────────────────────────────────────────────────────────────────┐
│ STEP 1: Verify Prerequisites                                         │
└─────────────────────────────────────────────────────────────────────┘

Required:
• Java 17 or higher
• Maven 3.6+
• MySQL 8.0+

Check your versions:
  java -version
  mvn -version
  mysql --version

┌─────────────────────────────────────────────────────────────────────┐
│ STEP 2: Setup MySQL Database                                         │
└─────────────────────────────────────────────────────────────────────┘

Option A - Automated (Linux/Mac):
  chmod +x setup-database.sh
  ./setup-database.sh

Option B - Manual:
  mysql -u root -p < src/main/resources/database/setup.sql

Option C - MySQL Workbench:
  Open: src/main/resources/database/setup.sql
  Execute all statements

┌─────────────────────────────────────────────────────────────────────┐
│ STEP 3: Configure Database Connection (if needed)                    │
└─────────────────────────────────────────────────────────────────────┘

If your MySQL username/password is different from "root"/"root":

Edit: src/main/java/com/quiz/quizera/utils/DatabaseConnection.java

Change these lines:
  private static final String USER = "root";      // Your MySQL username
  private static final String PASSWORD = "root";  // Your MySQL password

┌─────────────────────────────────────────────────────────────────────┐
│ STEP 4: Build and Run                                                │
└─────────────────────────────────────────────────────────────────────┘

Linux/Mac:
  ./mvnw clean javafx:run

Windows:
  mvnw.cmd clean javafx:run

🛠️ TROUBLESHOOTING:

Problem: "Connection refused" error
Solution: Check if MySQL is running
  sudo systemctl status mysql
  sudo systemctl start mysql

Problem: "Access denied for user" error
Solution: Verify MySQL credentials in DatabaseConnection.java

Problem: Maven build errors
Solution: Clean and rebuild
  ./mvnw clean install
  rm -rf target/
  ./mvnw clean compile

Problem: JavaFX errors
Solution: Ensure Java 17+ is installed and JAVA_HOME is set correctly

Problem: Module errors
Solution: Check that module-info.java includes:
  requires java.sql;
  opens com.quiz.quizera.controllers to javafx.fxml;
